ANJANA BIRTHDAY - FINAL V1

1. Open index.html in Chrome or Edge.
2. Keep the assets folder beside index.html.
3. Optional music:
   Put your MP3 beside index.html and rename it:
   birthday-song.mp3

GAME:
- Click Start.
- 7 flowers move around the box.
- Catch all 7 within 15 seconds.
- If time runs out, Try again appears.
- On winning, the sunflower screen appears.

IMPORTANT:
- Gallery and final photo use object-fit: contain so the original
  photos are NOT chopped/cropped.
- The Bharat Mata Ki Jai button keeps the Indian flag and gives
  a small respectful/funny reaction after clicking.
- No React, npm, server, or installation is required.


FLAG FIX:
- The Bharat Mata Ki Jai button now uses an inline SVG Indian flag, so it does not depend on Windows/Chrome emoji fonts.
- No external image or internet connection is required for the flag.
